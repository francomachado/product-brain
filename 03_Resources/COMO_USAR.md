# 📚 Como usar Resources

Resources são **conhecimento atemporal de referência** — não têm deadline, não são projetos.
Ficam aqui indefinidamente e são consultados por múltiplos projetos e áreas.

## Subpastas

| Pasta | O que vai aqui |
|-------|---------------|
| `Produtos_e_Solucoes/` | Documentação dos seus produtos — pode ser alimentada pelo scraper |
| `Mercado_e_Segmento/` | Benchmarks, análises de concorrentes, tendências |
| `Tecnologia_e_AI/` | Frameworks, ferramentas, referências técnicas |
| `Referencias_Externas/` | Artigos, livros, cases externos |

## Dica

Use o script em `06_Scripts/doc_scraper.py` para popular automaticamente
a pasta `Produtos_e_Solucoes/` com documentação pública dos seus produtos.
