# 🚀 Como usar Projects

Projects são iniciativas **com deadline e entregável claro**.
Quando o projeto encerra, ele vai para `04_Archives/`.

## Quando criar um projeto

- Tem objetivo definido
- Tem prazo (mesmo que estimado)
- Tem pelo menos um entregável concreto

## Como criar

1. Crie uma subpasta com o nome do projeto: `01_Projects/Nome_do_Projeto/`
2. Dentro dela, crie a nota principal usando [[TPL_Projeto]]
3. Adicione notas de reunião, features e decision records dentro da mesma pasta

## Estrutura típica de um projeto

```
01_Projects/Nome_do_Projeto/
├── Nome_do_Projeto.md          ← nota principal (TPL_Projeto)
├── Feature_X.md                ← features (TPL_Feature_Doc)
├── Reuniao_YYYY-MM-DD_tema.md  ← reuniões (TPL_Reuniao)
├── DEC_YYYY-MM-DD_decisao.md   ← decisões (TPL_Decision_Record)
└── Weekly_Report_YYYY-WNN.md   ← relatórios semanais (TPL_Weekly_Report)
```
