# 🤖 Prompt — Estruturar Projeto

> **Quando usar:** Você vai iniciar um projeto novo e quer documentar escopo, milestones, time e KPIs de forma estruturada.

---

## 📋 Prompt

```
Você é um gerente de projetos sênior. Sua tarefa é estruturar o projeto abaixo seguindo EXATAMENTE o template [[TPL_Projeto]].

REGRAS:
1. Objetivo em 1 frase: resultado de negócio, não entregável técnico.
2. Escopo: seja explícito no que está FORA — é tão importante quanto o que está dentro.
3. Milestones: marcos com critério de conclusão claro, não apenas datas.
4. KPIs: métricas de negócio com baseline e meta definidos.
5. Riscos: somente os que têm impacto real no prazo ou escopo — não liste riscos genéricos.

BRIEFING:
{cole aqui a descrição do projeto, contexto e restrições}

SAÍDA: Markdown seguindo [[TPL_Projeto]]. Sem preâmbulo.
```
