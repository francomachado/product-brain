# 📥 Como usar o Inbox

O Inbox é a **zona de entrada** de tudo que chega bruto — sem filtro, sem julgamento.

## Regra de ouro

> Tudo que cair aqui deve ser processado em ≤ 48h e movido para a pasta certa.

## Subpastas

| Pasta | O que vai aqui |
|-------|---------------|
| `reunioes_brutas/` | Transcrições de reuniões antes de processar |
| `ideias_rapidas/` | Pensamentos soltos, notas de voz transcritas, insights |
| `leituras/` | PDFs, artigos e referências a processar |

## Fluxo

```
Chega aqui → Processa com IA (PROMPT_Reuniao, etc.) → Move para 01_Projects ou 02_Areas
```
