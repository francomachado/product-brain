# 🗄️ Como usar Archives

Archives guardam **tudo que encerrou** — projetos concluídos, pausados ou cancelados.
Nunca delete; arquive. Um dia você vai querer saber "como fizemos isso antes".

## Como arquivar um projeto

1. Mova a pasta inteira de `01_Projects/Nome_do_Projeto/` para `04_Archives/YYYY/`
2. Atualize o status na nota principal para `concluido` ou `cancelado`
3. Remova os links do `00_Dashboard` se necessário

## Organização

As subpastas são organizadas por ano (`2024/`, `2025/`, `2026/`...).
Adicione anos conforme necessário.
